# Smart Blind Cane - Canne Connectée AfroIot

**FRANÇAIS**
Canne pour malvoyants avec détection obstacles ultrasons HC-SR04.
Alerte par buzzer + moteur vibration. Portée réglable 50cm-2m.
Matériel : Arduino Uno, HC-SR04, Buzzer, Moteur vibration 3V
Projet AfroIot Engineers 2025 - Objectif CSC 2027 Licence IoT

**ENGLISH**  
Ultrasonic blind cane using HC-SR04 sensor.
Alert via buzzer + vibration motor. Adjustable range 50cm-2m.
Hardware: Arduino Uno, HC-SR04, Buzzer, Vibration motor
AfroIot Engineers Project 2025 - CSC 2027 Goal Embedded Systems
